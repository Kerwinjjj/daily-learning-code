# C 指针基础 & 指针与数组（Day2 · 嵌入式必考）

> 以**代码和注释**为主，图表用于**比对**；英文缩写标注中文。固件开发天天用指针。

## 0. 一句话总结

指针（pointer）是**存放地址的变量**：`&` 取地址，`*` 解引用；**数组名是首元素地址，但不是指针**（`sizeof`（大小运算符）最能体现区别）；指针运算 `p++` 加的是一整个"类型步长"，不是 +1。

## 1. 指针本质（demo1）

```c
#include <stdio.h>

int main(void)
{
    int a = 100;            /* 普通变量：在栈上，有自己的地址和值 */
    int *p = &a;            /* 指针变量：p 存放 a 的地址（& 取地址） */

    printf("a 的值    = %d\n", a);
    printf("a 的地址  = %p\n", (void *)&a);   /* & 取地址 */
    printf("p 的值    = %p\n", (void *)p);    /* p 存的就是 a 的地址 */
    printf("p 的地址  = %p\n", (void *)&p);   /* 指针也是变量，自己也有地址 */
    printf("*p        = %d\n", *p);           /* * 解引用：取出指向内存的值 */

    *p = 200;                /* 解引用赋值 == 直接给 a 赋值 */
    printf("修改后 a  = %d\n", a);            /* 输出 200 */
    return 0;
}
```

**结论：** `p 的值 == &a`（指针存地址）；`*p` 等价于 `a`（可读可写）；`&p` 存在（指针自己也是变量）。

## 2. 数组名 vs 指针（sizeof 最能体现）

| 对比 | 数组名 `arr` | 指针变量 `p` |
|---|---|---|
| `sizeof(x)`（大小运算符） | 整个数组的字节数（`int arr[5]` → 20） | 指针本身的字节数（64 位 → 8） |
| 能否赋值 / 自增 | 不能（`arr = ...` 编译错误，`arr++` 不存在） | 能（`p++`、`p = arr + 2`） |
| 本质 | 编译器给定的**常量地址** | 存放地址的**变量** |
| `&x` 的含义 | `&arr` 是整个数组的地址 | `&p` 是指针变量自己的地址 |
| 身份保持的场景 | `sizeof`、`&`、字符串初始化时是数组 | 始终是指针 |

```c
#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};
    int *p = arr;                 /* 数组名 == 首元素地址（&arr[0]） */

    printf("sizeof(arr) = %zu\n", sizeof(arr));   /* 20：整个数组 */
    printf("sizeof(p)   = %zu\n", sizeof(p));     /* 8：指针变量（64 位） */

    /* arr = p; */                /* 错误：数组名是常量，不能赋值 */
    return 0;
}
```

> 细节：数组名在 `sizeof`、`&`、字符串初始化等场景保持"数组身份"；在其他表达式中会**退化成（decay）指向首元素的指针**——这也是 `sum_array(data, 5)` 传数组名就等于传指针的原因。

## 3. 指针运算：p++ 加的是"步长"（类型宽度）

| 指针类型 | 步长（p+1 移动的字节数） | 场景 |
|---|---|---|
| `int *` | 4 | 整数数组遍历 |
| `char *` | 1 | 字符串 / 缓冲区逐字节处理 |
| `uint16_t *`（无符号 16 位整型） | 2 | ADC（模数转换）采样数组 |
| `struct xx *`（结构体指针） | sizeof(结构体) | 结构体数组 |

**通用公式：`p + n == 地址 + n * sizeof(元素类型)`；`p[i] == *(p + i)`。**

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;
p++;                    /* 地址 +4 字节（int 宽度），p 指向 20 */
printf("%d\n", *p);     /* 输出 20 */
```

## 4. 练习1：遍历数组的两种写法（demo3）

```c
#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};
    int i;
    int *p;

    /* 写法一：下标 [] 方式 */
    printf("下标遍历：");
    for (i = 0; i < 5; i++) {
        printf("%d ", arr[i]);   /* arr[i] 等价于 *(arr + i) */
    }
    printf("\n");

    /* 写法二：指针自增方式 */
    printf("指针遍历：");
    for (p = arr; p < arr + 5; p++) {   /* p++：地址 + 4 字节（int 步长） */
        printf("%d ", *p);              /* 解引用当前指向的元素 */
    }
    printf("\n");

    return 0;
}
```

**两种写法对比：**

| | 下标方式 | 指针自增方式 |
|---|---|---|
| 原理 | `arr[i]` = `*(arr + i)` | 移动指针自己，`*p` 取当前元素 |
| 代码风格 | 直观、适合固定遍历 | 紧凑、适合边遍历边移动（读 FIFO（先入先出队列）、缓冲区） |
| 越界风险 | 相同（`i < n` / `p < arr + n`） | 相同 |

## 5. 练习2：用指针实现数组求和（demo4）

```c
#include <stdio.h>

int sum_array(const int *arr, int n)   /* 指针参数：数组首元素地址 + 长度 */
{
    int sum = 0;
    const int *p;

    for (p = arr; p < arr + n; p++) {
        sum += *p;                     /* 解引用逐个累加 */
    }
    return sum;                        /* 返回 int 值（不是地址），安全 */
}

int main(void)
{
    int data[5] = {1, 2, 3, 4, 5};
    printf("sum = %d\n", sum_array(data, 5));  /* 数组名退化为指针传入 */
    return 0;
}
```

**踩坑重点：** 返回的是 `sum` 这个 **int 值**，安全。**绝对不要**在函数里定义局部数组再 `return` 它的指针（见思考题）。

## 6. 思考题：为什么不能返回函数内部栈上数组的指针？

```c
int *bad(void)
{
    int arr[3] = {1, 2, 3};   /* arr 是栈上的局部数组 */
    return arr;               /* 危险！函数返回后 arr 已失效 */
}
```

**原因链条（面试按这个顺序说）：**

1. `arr` 是局部数组，存放在**栈**上，生命周期 = 函数调用期间；
2. 函数 `return` 时**栈帧销毁**，这块内存被回收；
3. 返回的指针成为**野指针（dangling pointer）**，指向已失效内存；
4. 之后任何一次函数调用都可能覆盖它——读到垃圾值、崩溃，最坏"碰巧还能读对"，最难排查；
5. 语言层面是**未定义行为（UB，Undefined Behavior）**。

**正确做法（4 选 1）：**

| 做法 | 写法要点 | 特点 |
|---|---|---|
| 返回数值本身 | `return sum;` | 最简单，"一个值"就用它 |
| 出参：调用方给缓冲区 | `void fill(int *out, int n)` | 嵌入式推荐，内存归属清晰 |
| static 局部数组（静态） | `static int buf[3]; return buf;` | 静态区全程存活，但下次调用覆盖、不可重入 |
| 堆上 malloc（动态分配） | `int *p = malloc(...); return p;` | 调用方必须 free；嵌入式慎用（碎片化） |

## 7. 常见误区速查表

| 误区 | 真相 |
|---|---|
| "数组名就是指针" | 数组名是常量地址，不是变量；`sizeof` 结果完全不同 |
| "p++ 是地址 +1" | p++ 加的是**一个元素步长**（int 为 4 字节） |
| "*p 只能读" | 可以写：`*p = 100`，等价于给指向的变量赋值 |
| "指针不用初始化" | 未初始化是野指针，解引用即崩溃；应赋 NULL（空指针）或有效地址 |
| "解引用前不用判空" | 对 NULL（空指针）解引用 → 段错误（Segmentation Fault） |
| "返回栈数组指针没事" | 栈帧销毁后是野指针，未定义行为（UB） |

## 8. 嵌入式视角（固件天天用）

- **读外设缓冲区 / FIFO（先入先出队列）**：`uint8_t *p = buf; while(len--) *dst++ = *src++;`，指针自增逐个搬数据；
- **函数传参省内存**：数组/结构体传指针，不整块拷贝，SRAM（静态随机存取存储器）省一点是一点；
- **寄存器访问**：外设寄存器就是固定地址，用指针映射：`*(volatile uint32_t *)0x40021000 = 1;`（volatile（易失）防止编译器优化）；
- **回调机制**：函数指针做回调（按键、定时器事件分发）；
- **const 习惯**：只读形参加 `const`（常量限定符），编译期防误改。
