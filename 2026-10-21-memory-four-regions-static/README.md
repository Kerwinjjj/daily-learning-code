# 2026-10-21 程序内存四区 & static 关键字

## 一、程序内存分区

| 分区 | 存放内容 | 生命周期 | 谁管理 |
|------|----------|----------|--------|
| 代码段（.text） | 编译后的机器指令（函数代码） | 整个程序运行期间 | 编译器 / 操作系统（只读，不可修改） |
| 只读常量段（.rodata） | 字符串常量、const 修饰的全局常量 | 整个程序运行期间 | 只读，修改会导致未定义行为（段错误） |
| 全局 / 静态区（数据段 .data + .bss） | 全局变量、静态变量（static） | 程序开始 → 程序结束 | 编译器负责初始化；static 局部变量只初始化一次 |
| 栈（stack） | 局部变量、函数参数、返回地址 | 函数调用 → 函数返回 | 编译器自动分配 / 释放 |
| 堆（heap） | malloc / free、new / delete 动态分配的内存 | 手动申请 → 手动释放 | 程序员手动管理 |

> 说明：教学中常称为"四区"（代码区、全局/静态区、栈、堆），只读常量段有时并入全局区、有时单独列为一区，视教材口径而定。地址高低因平台 / 编译器而异：x86-64 Linux 常见布局为 代码段低地址 → 只读常量 → 全局/静态区 → 堆（向上增长）→ 栈（向下增长，最高地址）。

## 二、区分三种变量的存储位置

- 局部变量（非 static）→ 栈，函数返回自动释放
- 全局变量 → 全局区（数据段），生命周期为整个程序
- 字符串常量 → 只读段，不能修改

## 三、static 的三种用法（嵌入式重点）

### 1. static 修饰局部变量 → 局部静态变量

- 存储位置：全局 / 静态区（不是栈）
- 生命周期：第一次进入函数时初始化一次，之后一直存活到程序结束
- 作用域：仍只在函数内部
- 用途：需要跨多次调用保持值的场景（计数器、状态标志等），见 demo2

### 2. static 修饰全局变量 → 全局静态变量

- 作用域限制为本源文件，其他源文件即使 extern 声明也无法访问
- 防止多文件项目中的命名冲突，实现文件级封装
- 生命周期不变，仍为整个程序

### 3. static 修饰函数 → 静态函数

- 函数仅在当前源文件内可见（内部链接）
- 其他文件即使 extern 声明也无法调用
- 用于模块内部工具函数，避免污染全局命名空间

## 四、面试口述题

### Q1：static 全局变量和普通全局变量区别？

- 存储位置、生命周期相同：都在全局区（数据段），都是程序开始到结束
- 链接属性不同：普通全局变量是外部链接（external linkage），其他源文件 `extern` 声明后可访问；static 全局变量是内部链接（internal linkage），只能在定义它的源文件内访问
- 作用：防止多文件命名冲突、实现文件内封装

### Q2：static 局部变量存放在哪个区？

- 存放在全局 / 静态区（数据段），而不是栈
- 特点：只初始化一次；生命周期是整个程序；作用域仍限于函数内
